## CN2 GIA 到底是什么，为什么“写着 CN2”还要自己验

CN2 GIA 全称 Chinatelecom Next Carrier Network - Global Internet Access，是中国电信国际精品网络里的顶级产品。回程基本全部走 59.43 高速节点，CN2 的 AS 号是 4809；少数省份没有 CN2 GIA 节点，会借道 202.97。

它的口碑来自晚高峰表现。白天不丢包是常态，晚高峰丢包率也压得很低，价格定位高、用户少，平时带宽有余量。代价是 GIA 整体出口带宽不大，遭受攻击时容易整段波动，普通用户一般碰不到。

对照组是普通 163 骨干网。有测评文章记录过同类型机器晚高峰从 40MB/s 掉到 2MB/s 的情况，这个数字是该文作者的叙述，不是可复现的实测，但晚高峰严重劣化这件事本身没有争议。

美西机房到国内的延迟量级在 140 到 180ms，这个数字引自第三方测评口径。想要 10ms 级别的延迟只有香港、东京节点能给，圣何塞给不了，指望它把国内访问做到“秒开”不现实。

回到 LightLayer。这条线被归在 Premium 网络下，公开描述是“CN2 优化线路”，有的地方写成 CN2/CMIN2，没有出现 GIA 字样。CN2 优化是个很宽的词，可能指去程走 CN2、回程走 163，也可能双向都走 59.43。同样的月付金额，走的是哪条路，差别全在回程上。

## 下单前用三条命令验线路

1. **用官方测试 IP 做 ping**，白天一次，晚上 21:00 到 23:00 再一次。看延迟数值，也看丢包率，晚高峰丢包超过一两个百分点就要警惕。
2. **在机器上对国内 IP 做 traceroute**，看路径里有没有 59.43 开头的节点。出现 59.43 且没有大量 202.97 借道，才算走对了线。
3. **去程和回程分别看**。只有回程走 59.43、电信去程还挤在 163 上的，不能按双向 GIA 来理解，这种配置晚高峰一样会难受。

这三步加起来不到二十分钟，比看任何一篇评测都准。同一个商家不同批次、不同 IP 段的线路都可能不一样，别人测通不代表你手上这台也通。
